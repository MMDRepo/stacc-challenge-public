# payforjoy

This project provides a solid foundation for the PayForJoy budgeting application with all the requested technologies and proper MVC architecture.

Features Implemented
Account Management: Create, view, update, and delete accounts
Transaction Tracking: Record and categorize income/expenses
Savings Goals: Set and track progress toward financial goals
Dashboard: Overview of financial status with charts
Reward System: Gamification elements to encourage saving
Error Handling: Comprehensive exception management
Logging: Detailed application logging
